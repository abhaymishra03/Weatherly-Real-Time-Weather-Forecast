# 🌤️ Weatherly - Weather Forecast App

Weatherly is a responsive weather application that provides real-time weather information and a 5-day forecast for any city. It uses the OpenWeatherMap API to fetch accurate weather data and provides a clean, user-friendly interface.

## 🚀 Features

- 🌍 Search weather by city name
- 📍 Get weather using current location
- 🌡️ Current temperature details
- 🌤️ Weather condition and dynamic icons
- 💧 Humidity information
- 💨 Wind speed details
- 🔽 Atmospheric pressure
- 👁️ Visibility information
- 📅 5-Day weather forecast
- 🔄 Temperature conversion between Celsius and Fahrenheit
- ⏳ Loading indicator while fetching data
- ❌ Error handling for invalid cities and location issues
- ⌨️ Search weather by pressing Enter

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeatherMap API
- Browser Geolocation API


## ⚙️ How It Works

1. User enters a city name or allows location access.
2. The app fetches weather data using OpenWeatherMap API.
3. The received data is displayed dynamically:
   - Current weather
   - Temperature
   - Weather condition
   - Additional weather details
   - 5-day forecast

## 🔗 API Used

OpenWeatherMap Forecast API

The application uses latitude/longitude or city name to retrieve weather information.
